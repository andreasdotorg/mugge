## US-155: Venue Audio Configuration — Markaudio CHN-50P + Dayton Ultimax UMII18-22 at 200Hz

**As** the system operator setting up for a gig,
**I want** a complete venue audio configuration for Markaudio CHN-50P mains
with a Dayton Ultimax UMII18-22 sub at a 200Hz crossover point,
**so that** I can deploy this speaker combination with correct FIR crossover
filters, gain defaults, and channel assignments on the Pi.

**Status:** selected
**Priority:** High (owner-directed, immediate implementation)
**Effort:** 1-2 worker days
**Origin:** Owner directive (session 15)
**Depends on:** US-115 (8ch filter-chain convolver — deployed)
**Blocks:** none
**Cross-references:** D-031 (driver protection filters), D-009 (cut-only
correction), D-063 (audio gate), US-113 (venue config model)

### Background

New speaker configuration for venue deployment:
- **Mains (ch 1-2):** Markaudio CHN-50P wideband drivers, 200Hz HPF
  minimum-phase FIR
- **Sub (ch 3):** Dayton Audio Ultimax UMII18-22 in 120L sealed enclosure,
  200Hz LPF minimum-phase FIR
- **Ch 4:** Spare (Dirac passthrough at zero gain)
- **Crossover:** 200Hz, all-FIR, no IIR. Combined minimum-phase FIR filters
  per the project's design principle (transient fidelity for psytrance).
- **Filter length:** 16,384 taps at 48kHz (341ms, 2.9Hz resolution)

**D-031 HPF exception for Ultimax:** The Ultimax UMII18-22 is an 18" subwoofer
in a sealed 120L enclosure. D-031 mandates HPF protection for all drivers.
For this sub, the LPF at 200Hz inherently limits excursion at high frequencies
where damage occurs. A subsonic HPF may still be applied by the FIR generation
pipeline (per the room correction workflow), but the D-031 mandatory HPF
requirement is documented as not applicable to a dedicated subwoofer channel
receiving only LPF-filtered content. This exception is documented in the
speaker identity YAML.

### Technical Notes

- The 200Hz crossover is higher than the typical 80Hz used with the Bose
  speaker system. This is appropriate for the CHN-50P which is a smaller
  wideband driver — 200Hz keeps the mains out of the range where they would
  struggle with excursion.
- The Ultimax UMII18-22 in 120L sealed has an F3 well below 30Hz — excellent
  sub-bass extension. The 200Hz LPF gives substantial overlap for smooth
  crossover integration.
- No topology changes to the filter-chain convolver are needed. The existing
  8ch config (US-115) supports loading different coefficient WAVs per channel.
  Only the WAV file contents and venue YAML change.
- Ch 5-8 (engineer HP, singer IEM) remain on Dirac passthrough per existing
  configuration.
