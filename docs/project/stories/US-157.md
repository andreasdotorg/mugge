## US-157: Mixxx Auto-Launch as NixOS Systemd User Service

**As** the DJ/operator,
**I want** Mixxx to launch automatically when the Pi boots into DJ mode,
**so that** I can power on the system at a venue and start DJing without
manually launching Mixxx via SSH or VNC.

**Status:** draft (design story — Architect recommended design review before implementation)
**Priority:** High (NixOS stabilization)
**Effort:** ~1 worker day (design) + ~1 worker day (implementation)
**Origin:** Session 15 — NixOS deployment missing Mixxx auto-launch
**Depends on:** US-072 (NixOS build — deployed), US-062 (boot-to-DJ mode — original concept, pre-NixOS)
**Blocks:** none
**Cross-references:** US-062 (boot-to-DJ, pre-NixOS implementation marked done),
D-042 (q1024 default), D-063 (audio gate)

### Background

US-062 (boot-to-DJ mode) was accepted on the pre-NixOS system where Mixxx
auto-launch was handled by a manual systemd user service. The NixOS migration
(US-072) did not carry over the Mixxx auto-launch service. A proper NixOS-native
implementation is needed.

**Design considerations (Architect to review):**

1. **Systemd user service:** Mixxx needs to run as a user service under `ela`
   (not a system service) because it requires the Wayland display (labwc) and
   PipeWire socket access.
2. **Dependencies:** The service must wait for PipeWire, WirePlumber, and the
   display server (labwc) to be ready before launching Mixxx.
3. **pw-jack wrapping:** Mixxx must be launched via `pw-jack mixxx` to use
   the PipeWire JACK bridge.
4. **Mode-dependent:** Mixxx should only auto-launch in DJ mode. If the system
   boots into standby or live mode, Mixxx should not start. This may require
   integration with GraphManager's mode state.
5. **Restart policy:** Should the service restart Mixxx if it crashes? What
   about the audio gate (D-063) — does a Mixxx crash/restart require re-opening
   the gate?
6. **Display requirements:** Mixxx needs a display. On headless boot (no HDMI),
   labwc + wayvnc provide a Wayland session. Verify Mixxx launches correctly
   in this scenario.

### Acceptance Criteria

- [ ] AC #1: **Design document.** Architect-reviewed design covering: systemd
      unit structure, dependency ordering, mode-conditional launch, restart
      policy, display requirements, and interaction with D-063 audio gate.
- [ ] AC #2: **NixOS systemd user service.** Mixxx auto-launch service declared
      in the NixOS configuration (not a manual drop-in). Launches `pw-jack mixxx`
      after PipeWire and display server are ready.
- [ ] AC #3: **Mode-conditional.** Mixxx only auto-launches when the system is
      in DJ mode (or the design document explicitly justifies always-launch with
      rationale).
- [ ] AC #4: **Verified on Pi.** After `nixos-rebuild switch` and reboot, Mixxx
      is running and visible via VNC. Audio routing is established by GM.
- [ ] AC #5: **Headless operation.** Mixxx launches correctly when no HDMI
      display is connected (labwc + wayvnc provide the Wayland session).

### Definition of Done
