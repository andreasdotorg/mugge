## US-160: Hercules DJControl Mix Ultra NixOS Verification

**As** the DJ,
**I want** to verify that the Hercules DJControl Mix Ultra works with Mixxx
on the NixOS Pi deployment,
**so that** I can confirm DJ controller hardware readiness for the upcoming gig.

**Status:** selected
**Priority:** High (gig-blocking, must-have)
**Effort:** < 0.5 worker days (hardware test only)
**Origin:** Session 16 gig sprint — G-02 gap
**Depends on:** US-072 (NixOS build — deployed), US-157 (Mixxx auto-launch)
**Blocks:** none
**Cross-references:** US-005 (pre-NixOS verification — done), G-02 (DJ parity gap)

### Background

US-005 verified the Hercules DJControl Mix Ultra on the pre-NixOS (Debian)
system in March 2026. The NixOS migration (US-072) deployed Mixxx controller
mappings via tmpfiles `C` rules (session 16), but the hardware has not been
physically plugged in and tested on NixOS. This story covers the NixOS-specific
verification.

The Mixxx mapping files are already deployed to `~/.mixxx/controllers/` via
NixOS tmpfiles. `alsa-utils` and `usbutils` are in the NixOS config. This is
a pure hardware verification — plug in the controller and confirm it works.

### Acceptance Criteria

- [ ] AC #1: **USB enumeration.** Hercules DJControl Mix Ultra visible in
      `lsusb` output on the NixOS Pi.
- [ ] AC #2: **MIDI device recognized.** Controller appears as a MIDI device
      in `aconnect -l` or equivalent ALSA sequencer listing.
- [ ] AC #3: **Mixxx detects controller.** Mixxx recognizes the Hercules
      controller and loads the deployed mapping. Verified via Mixxx preferences
      or controller indicator in the UI.
- [ ] AC #4: **Basic DJ operations work.** Play/pause, crossfader, volume
      faders, and jog wheels function correctly. Verified by VNC observation
      during Mixxx playback.
- [ ] AC #5: **Any non-functional controls documented.** If specific controls
      do not work, document them for future mapping refinement.

### Definition of Done

- [ ] All acceptance criteria met
- [ ] Test performed on NixOS Pi (192.168.178.35) with physical hardware
- [ ] Lab note documenting results
