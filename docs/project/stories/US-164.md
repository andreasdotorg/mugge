## US-164: Live Mode End-to-End Verification on NixOS Pi

**As** the live vocalist/operator,
**I want** to verify the complete live mode signal path on the NixOS Pi,
**so that** I can confirm live vocal performance is fully operational before
the gig.

**Status:** selected
**Priority:** Critical (gig-blocking, must-have)
**Effort:** ~1 worker day (Pi hardware session required)
**Origin:** Session 16 gig sprint — live mode never tested on NixOS
**Depends on:** US-162 (Reaper service), US-163 (capture adapter re-enablement),

**Blocks:** none
**Cross-references:** CLAUDE.md IEM signal path, D-063 (audio gate),

### Background

Live mode has never been tested end-to-end on the NixOS deployment. The entire
signal path must be verified with actual hardware:

- **Mic input:** Vocal mic -> ADA8200 preamp -> ADAT -> USBStreamer ch 1 ->
  PipeWire capture -> Reaper input
- **PA output:** Reaper -> PipeWire -> convolver (mains HPF, sub LPF) ->
  USBStreamer ch 1-4 -> ADA8200 -> amplifier chain
- **IEM output:** Reaper -> direct PipeWire link -> USBStreamer ch 7-8
  (bypasses convolver entirely per CLAUDE.md IEM signal path)
- **Quantum:** 256 (live mode, ~5.3ms PA path latency)
- **GM mode:** live (different link topology from DJ)

### Acceptance Criteria

- [ ] AC #1: **GM live mode active.** GraphManager enters live mode
      successfully. `pw-link -l` shows live mode link topology (Reaper ->
      convolver for mains/subs, Reaper -> direct USBStreamer for IEM).
- [ ] AC #2: **Quantum 256.** PipeWire quantum is 256 in live mode.
      Verified by `pw-metadata -n settings` or `pw-top`.
- [ ] AC #3: **Mic input working.** Audio from vocal mic reaches Reaper
      input channels. Verified by Reaper level meters or signal-gen
      measurement.
- [ ] AC #4: **PA output working.** Reaper playback (backing track) reaches
      USBStreamer ch 1-4 through the convolver. Verified at safe volume via
      headphones on ch 5-6 or spectrum monitoring.
- [ ] AC #5: **IEM output working.** Reaper IEM mix reaches USBStreamer ch 7-8
      via direct PipeWire link (bypassing convolver). Verified by monitoring
      ch 7-8 output.
- [ ] AC #6: **Latency acceptable.** PA path latency at q256 is ~5.3ms (well
      below 25ms slapback threshold). Verified by calculation or measurement.
- [ ] AC #7: **No xruns during live playback.** 10-minute live mode playback
      session with Reaper produces zero or near-zero ERR in `pw-top`.

### Definition of Done

- [ ] All acceptance criteria met
- [ ] Test performed on NixOS Pi with physical audio hardware (USBStreamer,
      ADA8200, microphone)
- [ ] AE consultation: review IEM bypass routing and latency assessment
- [ ] Lab note documenting signal path verification results
- [ ] Owner acceptance: live mode works for vocal performance
