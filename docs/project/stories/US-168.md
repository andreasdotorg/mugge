## US-168: Room Correction Dry Run — End-to-End Measurement Pipeline Test

**As** the audio engineer/operator,
**I want** to run the complete room correction measurement pipeline at a
test venue, generate venue-specific FIR coefficients, deploy them to the Pi,
and verify the corrected response,
**so that** I can confirm the measurement workflow is operational before the gig.

**Status:** selected
**Priority:** Low (nice-to-have)
**Effort:** ~2 worker days (measurement session + pipeline run + deployment)
**Origin:** Session 16 gig sprint — room correction readiness
**Depends on:** US-155 (venue audio config deployed), US-164 (live mode E2E),
US-096 (UMIK-1 calibration pipeline — REVIEW)
**Blocks:** none
**Cross-references:** docs/theory/ (measurement theory), US-120 (real-time
transfer function), US-098 (room correction pipeline verification),
design principle 6 (one-button per venue)

### Background

The automated room correction pipeline exists (US-098 verified P1/P2) but has
never been run end-to-end on the NixOS Pi with the actual measurement hardware
(UMIK-1) at a real venue. This story covers a dry run — ideally at the home
setup or rehearsal venue — to validate the complete workflow:

1. Place UMIK-1 at listening position
2. Run measurement (signal-gen sweep -> UMIK-1 capture -> transfer function)
3. Generate venue-specific FIR coefficients (combined crossover + correction)
4. Deploy coefficients to Pi (`/etc/pi4audio/coeffs/`)
5. Verify corrected response matches target

This is a "nice-to-have" for the gig — the crossover-only filters from US-155
provide a functional baseline without room correction. Room correction improves
quality but is not blocking.

### Acceptance Criteria

- [ ] AC #1: **Measurement captured.** UMIK-1 measurement sweep captured
      successfully on the NixOS Pi using signal-gen + pcm-bridge (or
      equivalent pipeline). Transfer function data saved.
- [ ] AC #2: **FIR coefficients generated.** Room correction pipeline
      generates combined minimum-phase FIR coefficients (crossover +
      correction) for all active output channels. 16,384 taps, 48kHz.
- [ ] AC #3: **D-009 compliance.** Generated filters are cut-only (no boost
      above 0 dB). Verified by inspecting filter magnitude response.
- [ ] AC #4: **Deployed and verified.** New coefficients deployed to Pi,
      PipeWire filter-chain reloaded, corrected response measured and
      compared to target. Improvement documented.
- [ ] AC #5: **Workflow documented.** Step-by-step record of the dry run
      added to the pre-flight checklist (US-167) or as a standalone
      measurement procedure document.

### Definition of Done

- [ ] All acceptance criteria met
- [ ] AE consultation: review measurement methodology and correction quality
- [ ] Lab note with measurement data, before/after response plots
- [ ] Owner review: workflow is practical for venue setup time constraints
